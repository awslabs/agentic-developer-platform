This is an explicit CPython3.11.16 port of the five reviewed upstream3.13
security changes listed in provenance.json, not a claim of merged3.11 fixes.
The three original image files exactly match the retained upstream3.11.16
source hashes. The canonical apply helper verifies every before/after hash and
patches with zero fuzz. The canonical five boundary tests run during the build.

Stringprep is generated for Python3.11's Unicode14.0 database using the exact
upstream generator and RFC3454 bytes. The upstream generator is retained as a
source-reference text artifact, `mkstringprep.py.txt`, with its SHA256. To
reproduce, place `rfc3454.txt` at `Tools/unicode/data/rfc3454.txt` in a disposable
working directory, then run `python3.11 mkstringprep.py.txt` with network disabled
and compare stdout to the patched stringprep.py hash. Do not replace the
Unicode version assertion over tables generated by a different runtime.

The urllib scheme and tar path/filter changes retain the upstream logic.
The hardlink change resolves the target before os.link, adapted to3.11's
branch, which lacks3.13's preceding unlink-if-existing block. No unrelated
hardlink behavior is imported.

All five canonical methods fail on the original3.11 image (ten subtest
failures); all five pass with these exact files. The remaining seven original
Python3.11 observations are unresolved and are not suppressed or accepted.
