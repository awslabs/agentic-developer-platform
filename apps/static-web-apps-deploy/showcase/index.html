Infrastructure & Security

  • S3 Buckets — Private, SSE-S3 encrypted at rest, no public access
  • CloudFront — TLS 1.2+ encryption in transit, global CDN edge caching
  • Origin Access Control (OAC) — Only CloudFront can read from S3
  • Least-Privilege IAM — Minimal permissions for each component
  • SPA Routing — Custom error responses for client-side routing support
  • HTTP/2+3 — Modern protocols for optimal performance
  • PriceClass_100 — Cost-optimized (NA + EU edge locations)
