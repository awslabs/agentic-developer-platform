### MEDIUM — discuss before merge
- `agent_learning/2026-06-11-issue-1361-learnings.md` — The AGENTS.md doesn't explicitly prohibit agent_learning files, and other merged PRs have included them (per agent history). **No action needed** but noting the file exists.
- TESTING.md §12 references `fixture-repo-private/` and `fixture-repo-public/` directories under `tests/fixtures/` that are NOT created in this PR. The actual fixture repos are expected to be created by sibling issues — acceptable since the doc is the plan and the actual directories are live-test dependencies.

### LOW — follow-up candidates
- The `code-index-fixture.json` is referenced by TESTING.md but not actually consumed by any test in this PR (tests use inline fixtures). Not a blocker — sibling issues (#1355) will use it.
- The `FakeACLStore.filter_results` method treats `""` (empty string) as a valid non-None principal, but the `TestMalformedIdentity` test manually handles the whitespace→None mapping in the test itself rather than in the store. Future production code should handle this in the filter itself. This is intentional — the test documents the expected behavior for the production implementation.
