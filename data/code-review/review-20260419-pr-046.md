### IAM Analysis

**Runner identity policy addition:**
- `execute-api:Invoke` on `arn:aws:execute-api:${region}:${account}:*/*/*/agent/*`
- This correctly scopes runner access to only the `/agent/*` paths (IAM-authenticated)
- Runners cannot invoke human-facing paths (`/{proxy+}`)

**Runner boundary addition:**
- `execute-api:*` on `Resource = "*"`
- Appropriate for a boundary — it sets the maximum permissions ceiling
- The identity policy's scoped resource pattern provides the actual restriction
