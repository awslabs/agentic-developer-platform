## Findings (by confidence)

### HIGH — merge blockers

- **`agent_learning/2026-06-07-issue-1226-learnings.md` committed to the PR**: AGENTS.md line 19 explicitly states: "Never commit `agent_learning/*.md` — that directory is gitignored; explicit `git add` bypasses the ignore and has caused drift five times already." This file MUST be removed from the PR before merge.

### MEDIUM — discuss before merge

- **Bedrock IAM policy uses `Resource = ["*"]`** (main.tf:166): The app role grants `bedrock:InvokeModel` and `bedrock:InvokeModelWithResponseStream` on all models. For an isolated experiment with limited blast radius this is acceptable, but could be scoped to `arn:aws:bedrock:us-east-1::foundation-model/anthropic.*` and `arn:aws:bedrock:us-east-1::foundation-model/amazon.titan-embed-text-v2*` for defense-in-depth. Not blocking.

- **RDS engine version `16.4` may not be available in all regions**: PostgreSQL 16.4 is relatively new on RDS. The deployment issue notes mention this was encountered. If it fails, fallback to `16.3` or use `16` without a minor version to get the latest available. Not blocking since the tfvars can override.

### LOW — follow-up candidates

- **`force_delete = true` on ECR repository** (storage/main.tf:44): Useful for experiment teardown, but means accidental `terraform destroy` would lose all images without confirmation. Acceptable for research module.

- **No CloudWatch alarms defined**: The EXPERIMENT.md mentions monitoring `HealthyHostCount` on the ALB, but no `aws_cloudwatch_metric_alarm` is defined in Terraform. This could be a follow-up to add an alarm that alerts if uptime drops below 95%.

- **ALB name length**: `adp-research-gbrain-alb` is 23 chars which is fine (limit is 32 for ALBs).

## Recommendation

**REQUEST CHANGES** — Remove `agent_learning/2026-06-07-issue-1226-learnings.md` from the PR. After that single fix, this PR is ready to merge. The Terraform is well-structured, properly isolated, follows established patterns (remote state refs, account-ID-suffixed S3 buckets), and all acceptance criteria are satisfied.
