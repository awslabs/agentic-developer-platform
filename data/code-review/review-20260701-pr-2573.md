## Security assessment

**MUTABLE tags carry a known supply-chain risk**: if an attacker gains ECR push access, they could replace `:latest` with a malicious image. However:
1. K8s deployments pin to commit SHA tags (not `:latest`), so deployed workloads are unaffected
2. `:latest` is only used for development convenience (e.g., local testing)
3. The prod gateway environment explicitly retains `IMMUTABLE` in its tfvars
4. ECR repository policies + IAM restrict who can push images
5. Image scanning on push is enabled (`scan_on_push = true`)

The risk is acceptable for this use case.
