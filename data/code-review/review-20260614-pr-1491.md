## Findings (by confidence)

### HIGH — merge blockers

None found. All acceptance criteria satisfied.

### MEDIUM — discuss before merge

1. **`codebuild/bs-agent-context-image.yml` line 4: stale "all 4" comment** — Header says "Shared by all 4 agent-context CodeBuild projects" but the Terraform now creates 5. The Terraform file (main.tf) was correctly updated to say "5", but the buildspec comment wasn't. Minor doc inconsistency, not a functional issue.
   - **Impact**: None (documentation only)
   - **Verdict**: Non-blocking; can be fixed in a follow-up

2. **`deploy.sh` --help text line 36: cost says `~$80/mo`** — The help text for `--personal-context-only` says "Cost: ~$80/mo" but the deploy summary (line 348) was updated to say "~$280/mo". Inconsistency within the same file.
   - **Impact**: User-facing help text is inaccurate
   - **Verdict**: Non-blocking; cosmetic

3. **Staging copies `door/` and `personal_context/` to ALL image build dirs** — The buildspec unconditionally copies these dirs into every image's build context (same pattern as `alembic/`). This is wasteful (adds ~1-5 MB to ingestion/deepwiki/litellm-proxy/codegraph-context builds) but harmless since those Dockerfiles never COPY these directories.
   - **Impact**: Slightly larger CodeBuild artifact, no functional impact
   - **Verdict**: Non-blocking; acceptable trade-off for simplicity

### LOW — follow-up candidates

1. **`validate.sh` line 170 uses `check_warn` for tool listing failure** — If the /tools endpoint is unreachable, this should arguably be `check_fail` not `check_warn` since the Door's tool surface is its primary purpose. However, during initial deploy before the image is built, a warning is more appropriate to avoid failing validation on first deploy.
   - **Verdict**: Current choice is reasonable for the initial deploy scenario.

2. **`deploy.sh` sources `_common.sh` twice** (line 120 and line 166) — The second source at line 166 is redundant since it was already sourced at line 120. Not harmful (idempotent), just unnecessary.
