## Security Review

### Scan: Hardcoded secrets and credentials

### Scan: Command injection
- **Finding**: `eval "$varname='$input'"` in `lightweight-setup.sh` line 44 (the `prompt()` function).
  - **Risk**: Medium. User-supplied input from `read` is passed through `eval`, which could execute arbitrary commands if the input contains shell metacharacters.
  - **Fix applied**: Replaced with `printf -v "$varname" '%s' "$input"` which safely assigns to a named variable without eval.

  - `--force-delete-without-recovery` in teardown is intentional and gated behind explicit `yes` confirmation.
