## Distinct provider and latency gates

#6935's foundation node passing does **not** implement its still-open `DEP03-c2` real installed-record provider. PR #7040 contributed bounded diagnostics; #6896/#6927 were provider design, not the installed-record integration. #6935 must join the **real** installed release ledger/provider and run `DEP02-t2`, `DEP02-t5`, `DEP03-t2` against a provider-backed fixture. #6937 retains live access/redaction/failure checks. Separately, #7200/#7201 must prove the Crew/Claude gateway **model** provider prerequisite. Neither is discharged by a manual installation or by the other provider passing.

#7175 owns the E49 latency/cost driver. Its matched baseline requires the same region, client path, model/version, scripted prompts, output-size class, concurrency and fixture state; include failures/timeouts in the denominator and distinguish durable ACK, first token and **first useful output**. Proposed foundation verdict: p95 durable ACK ≤3 s, warm first-useful-output and persistent follow-up p95 each improve ≥20% over a matched baseline with ≤10% p50 regression, plus zero auth/data-loss failures. Gather roughly 30 samples per mode as an initial release check, split deterministic transport and real-model results, and record idle/node and model spend. [Gateway memory's additional recall p95 ≤250 ms](memory-backup-contract-6930.md#gateway-agentcore-adapter--7210) is a **separate unmeasured target**; it cannot turn a missing baseline into a pass. Because warm capacity and persistence have already merged, whether the `feature off` WARM01 mode is an acceptable historical baseline remains an **owner decision** under #7175, not a known measurement. #6937's authorized live run must bind the actual deployed revision/target, model, cost cap and cleanup before claiming latency acceptance. No live run or capacity change is authorized by this document.

**Upgrade rule:** for each new Crew/ACP/Claude/embedding/checkpoint combination, re-pin wheel/npm/image/model byte hashes; run a clean profile and V1/V2 restore/migration plus private sandbox, client protocol, gateway model route, rollback and negative credential/isolation checks. Keep old checkpoints readable or explicitly migrate them before changing the live pointer. If any prerequisite fails, retain the previous verified profile and report `incompatible`, not `ready` or a silently substituted provider. #7201/#7202/#7222 own their implementation evidence; #7215/#7223 review repository checks; #7217/#6937 own distinct live gates.
