## The problem in plain terms

Users receive source-backed recommendations with honest limitations, and a later authorized design task can use the same version even after owned provider setup is cleaned up.

**The fix in one line:** Publish attributable recommendations and prove later entitled design reuse.

## Impact analysis

Test scope leaks, duplicate paid work and unsafe cleanup. Existing budgets apply; no allowance renewed. Operational evidence remains private.

## Design

**Approved design:** Accepted 2026-10-27 at `109fd8df85783557ea0efc4bba0ada53355f5c74`; [canonical slice][design]; [actual review](https://github.com/aws-e/adp/pull/9106#pullrequestreview-5669812097).

**Reuse:** Shared L5 SQL/workers, Product APIs/broker and contracts; canonical audit pins main/open-PR evidence. WA entry points are proposed.

**Contract:** Paginate profile recommendations, Get each and filter exact generationId; preserve native IDs/raw private artifacts and strict source-only result variant. Independent source/goals comparison records supported/contradicted/not_verifiable/not_checked with real citations. Scope-compatible comparisons only. Durable per-result/version/destination/schema publication keys recover lost acknowledgement without paid reruns. Current source visibility and revocation watermark govern artifacts/query/counts and later reuse.

**Owned/advisory files:** Existing result/findings/triage APIs/models; proposed WA recommendation normalizer/comparison tests; shared SA11 publication worker/models and Context/Insights adapters, coordinated with #8693/#8149. Do not reuse DevOps space-knowledge rows or orchestration tracker outbox as a new result sink.

**Dependencies:** #9101. **Prerequisites:** WA04 native results and WA03 manifest; shared SA11 #8693/Context #8149/Insights owners must expose admitted schema, receipt readback and denied-reuse behavior. Unsupported consumers block publication/EC-07, not result persistence/comparison work. WA07 integrates live later-task proof.

## Deployment

WA07/#8698 integrate one compatible schema/worker/client batch; retain normal gateway/frontend auto-deploys. Existing authority, no new gate. Preserve unknown sources/adopted resources; reconcile original intent. Blocked live ACs remain incomplete.
