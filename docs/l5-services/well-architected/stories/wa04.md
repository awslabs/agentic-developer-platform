## The problem in plain terms

## Design

**Approved design:** Accepted 2026-10-27 at `109fd8df85783557ea0efc4bba0ada53355f5c74`; [canonical slice][design]; [actual review](https://github.com/aws-e/adp/pull/9106#pullrequestreview-5669812097).

**Reuse:** Shared L5 SQL/workers, Product APIs/broker and contracts; canonical audit pins main/open-PR evidence. WA entry points are proposed.

**Contract:** Commit pinned documented `s3Uri`, `s3VersionId` and Framework `lensArns` request, stable name/profile/model hash and attempt before Start; independently confirm Product scope, Profile eligibility, complete manifest and S3 version/bytes before paid work; disable SDK mutation retries. Immediate after-commit dispatch plus existing bounded SQL recovery handles lost queue sends. Lost Start response reconciles original profile/name/scope identity, never blind retry. Due observation preserves last known native state; unsupported cancellation/local expiry retains source holds and allows later collection. Extend shared terminal-local-state recovery, not just the adapter enum. Native completion starts collection, not a new paid run.

**Owned/advisory files:** Existing admission/dispatcher/work_store, workers/execution and recovery, adapter protocol; proposed adapters/well_architected/generation.py and installed-worker fault tests. WA07 coordinates common worker and PR #9081 changes; retain Security cancellation compatibility.

**Dependencies:** #9099, #9100. **Prerequisites:** WA01 safe native identity/no-effect semantics, WA02 ready binding, WA03 provider-readable archive/holds. #8698 release transport/factory and WA07 eligible fixture enable installed live fault proof; absence blocks only dependent phase.
