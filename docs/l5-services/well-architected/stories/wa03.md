## Design

**Approved design:** Accepted 2026-10-27 at `109fd8df85783557ea0efc4bba0ada53355f5c74`; [canonical slice][design]; [actual review](https://github.com/aws-e/adp/pull/9106#pullrequestreview-5669812097).

**Reuse:** Shared L5 SQL/workers, Product APIs/broker and contracts; canonical audit pins main/open-PR evidence. WA entry points are proposed.

**Contract:** Admission pins source RecordRefs/snapshot hashes, byte/file bounds, goals/context and selected-tree coverage. Deterministic archive/manifest maps every selected artifact and entry to component or explicit exclusion; reject unsafe paths, secrets, oversized or unsupported inputs, never execute IaC or silently truncate. Read back immutable S3 object version and bytes before Start; read generation/recommendation source references after Start. Unknown per-file provider consumption remains an explicit limitation, never a fabricated receipt. Persist tenant/artifact/run hold until remote terminal proof; revoked access hides reuse but does not trigger destructive deletion. No Profile SQL or new crawler.

**Owned/advisory files:** Existing ProductClient/source_manifest and gateway Product snapshot integration; proposed WA source packaging/provider handoff tests and shared source-retention model/migration. WA03 owns retention semantics; #8684 owns Product source APIs; WA07 integrates shared schema/store changes.

**Dependencies:** #9098, #9099. **Prerequisites:** WA01 must qualify additionalContext/file/byte/role/provider readback semantics; WA02 supplies ready source-only binding. Documented ZIP, folder and per-file limits govern packaging; unverified live access and per-file ingestion remain explicit acceptance limitations, not permanent pre-Start blockers. WA07 supplies authorized private store/fixtures.
