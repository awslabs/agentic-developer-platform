## Design

**Approved design:** Accepted 2026-10-27 at `109fd8df85783557ea0efc4bba0ada53355f5c74`; [canonical slice][design]; [actual review](https://github.com/aws-e/adp/pull/9106#pullrequestreview-5669812097).

**Reuse:** Shared L5 SQL/workers, Product APIs/broker and contracts; canonical audit pins main/open-PR evidence. WA entry points are proposed.

**Contract:** Register proposed well_architected/architecture_review as typed service/capability variants; mixed immutable document/repository_commit inputs, four documented architecture-review pillars and source_only mode. Record SDK model hash and documented S3 source/version/size/Region/pillar/lens/quota semantics; preserve unknown live eligibility and per-file ingestion as uncertainty and safe no-effect/reconciliation rules. Native Start has no client token in the inspected model; local timeout is not cancellation. Public requests cannot carry authority or arbitrary SDK arguments. Existing Security/DevOps callers remain compatible.

**Owned/advisory files:** Shared contracts/v1 catalog, schemas, OpenAPI, operation/MCP matrices and compatibility fixtures; L5 run_input/configuration registration; proposed adapters/well_architected qualification fixtures and docs. Coordinate common edits with #8683 and DevOps PR #9081; no platform constants.

**Dependencies:** None; first qualification slice. **Prerequisites:** Eligible private provider fixture and authoritative Module/Feature catalog mapping are unverified. WA01 records qualification evidence; WA07 supplies eligible access; PranavSharma1000 resolves catalog IDs. Live contract qualification/activation and dependent dispatch are affected, not independent schema work.
