## The problem in plain terms

A provider saying a change is complete does not prove the patch is safe or its tests ran. Reviewers need the original change and independently checked evidence that remains readable after scratch cleanup.

**The fix in one line:** Return immutable provider provenance and real before/after verification instead of inferred success.

**Approved design:** Accepted 2026-10-27 at `f02387465846acbb9eda244f5815c0ab224ea87a`; [actual review](https://github.com/aws-e/adp/pull/9103#pullrequestreview-5669811881).

**Owned canonical sections:** [patch test and result provenance](https://github.com/aws-e/adp/blob/f02387465846acbb9eda244f5815c0ab224ea87a/docs/l5-services/transform/architecture.md#patch-test-and-result-provenance), [identity and isolation](https://github.com/aws-e/adp/blob/f02387465846acbb9eda244f5815c0ab224ea87a/docs/l5-services/transform/architecture.md#identity-and-isolation), [execution and recovery](https://github.com/aws-e/adp/blob/f02387465846acbb9eda244f5815c0ab224ea87a/docs/l5-services/transform/architecture.md#execution-and-recovery).

**Starting point:** At main `388584bdd80a4a5ff142abe3234e7d1eac1cfd64`: L5 provider observations/results/result_details and Security-only result artifact routes. Shared artifact store and TF01 strict result schema; do not force patches into Security finding rows.

- **Deliverables/entry points:** Proposed Transform normalizer/verifier in L5 plus typed result/artifact host extension. Preserve provider raw diff/tree before normalization; detached trusted checks are outside editable source. No source fixes or paid reruns hidden inside collection.
- **Inputs/outputs:** Input: sealed source manifest, original provider output/session identity and pinned test policy/images/bundles. Output: original patch digest, actual base/candidate tree identity, changed files, manifest/lock comparison, per-command before/after results and limitations.
- **State/auth/recovery/compatibility:** Do not invent candidate commit, passing exit codes or provider attribution. Check traversal/write scope independently; parse dependency/lock artifacts rather than trust provider summary. Keep failed/not-run/inconclusive tests distinct. Hash-readback retained artifacts before cleanup; current authorization on every artifact read. Collection retries never restart paid work. Reuse shared SQL keys and compatible old readers.
- **Prerequisites:** TF03 supplies original native artifacts; TF01 schema and independently pinned oracles/images. Provider live access affects live proof only; fixtures can verify deterministic rejection paths before review.

Paths are advisory, not write grants or node failure gates. Canonical sections own detailed schemas/limits; do not fork the architecture.
