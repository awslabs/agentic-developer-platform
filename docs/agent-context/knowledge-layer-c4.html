Cross-cutting components (in the worker)

StageTracker

stage_tracker.py

Creates the run_id header; wraps each stage: attempt → write → verify → record. Writes index_runs / index_run_stages.

ACL filter

door/acl.py

Derives allowed_principals from GitHub; the MCP server applies it fail-closed on every result.

Config

config.py (pydantic)

Single typed settings source; per-task model tiering.

The verify-after-write contract: a stage is marked verified only after a read-back confirms the artifact actually exists (S3 head_object / vector count>0 / Postgres rows). Skip/retry keys off verified, never a SHA — so "status says done, store empty" can't recur. (Caveat: tracking only writes if the worker has a live DB connection — the migration must have applied.)
