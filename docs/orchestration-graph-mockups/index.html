Inception

The front of the funnel: capture an intent by writing a plain thought, then the stage-review experience — what the agent found in summary form, deep links to the full documents, and the decisions only you can make rendered as pickable option cards instead of comment threads.

 Option A

Transit

The loop as a metro line: stations are stages, human gates are interchanges, parallel stories are branch tracks, the agreed-but-unrun plan is dashed track ahead. A departures board carries live runs and controls.

Strongest at: stakeholder legibility — the story in one glance.
 Option B

Mission Control

A dark operator console: clickable DAG canvas, an inspector drawer with per-node transitions, heartbeat log and actions (resume / abort / gate), and a telemetry strip with cost and SLO state. Temporal/Buildkite lineage.

Strongest at: operating — drill-down, controls, live state density.
 Option C

The Ledger

The graph as a chronicle the engine writes and humans sign: plain-sentence entries for every transition, inline gate and stall cards where action is needed, cost in the margin, the future in future tense.

Strongest at: human understandability — a non-author can read the whole journey.

These are static mockups with illustrative data (option B's nodes are clickable). They exist to pick an interaction model before dashboard stories are cut — the winning direction (or hybrid) feeds the wave-1 UX spike mandated in the delivery plan. Nothing here is production code.
