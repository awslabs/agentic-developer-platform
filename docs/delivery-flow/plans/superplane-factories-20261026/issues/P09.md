## The problem in plain terms

Operators need a reliable way to implement the Nebius cluster factory adapter. The current implementation does not yet provide this outcome under the four-layer factory contract.

**The fix in one line:** Implement the Nebius cluster factory adapter.

## Description

- **Parent / reports to:** https://github.com/aws-e/adp/issues/8950.
- **Delivery owner:** ADP delivery-flow coordinator assigns the SPF-P09 implementer; the coordinator owns integration and finding closure.

- **Completion boundary:** Merged implementation and its relevant tests; live deployment/acceptance is owned by batch R3 release/verification stories.
- **In scope:** Implement managed Kubernetes create/adopt/observe/retire through the approved provider adapter and existing execution owner. Bind cluster identity, initial capacity, private access and ongoing Argo identity to the common readiness contract. Consume the reviewed P14 infrastructure recipe; do not introduce a second provider-infrastructure implementation.
