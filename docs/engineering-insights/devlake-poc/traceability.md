Supplemental EC-11 is defined in the [provider amendment](provider-expansion.md)
and implemented by [S14](stories/s14.md), AC-01–05. It requires new live proof
for all seven selected providers and scoped cleanup/retention in addition to the original 44
criteria below. Original identities/results remain unchanged.

The [architecture](architecture.md) is the design baseline authorized for merge. Each row names the existing story and required independent evidence. Existing EC/AC/SCN IDs remain; [review amendments](review-amendments.md) and the subsequent [optional deployment amendment](optional-deployment.md) record strengthened tables plus S02 AC-05, S10 AC-04 and S11 AC-04 (44 AC/SCN pairs).
