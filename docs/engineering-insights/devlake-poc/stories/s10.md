## Interfaces, data and authorization

Architecture §4 defines the proposed one-page internal API, operation context, errors and cursor adapter. Go sends only allowlisted provider actions through ADP; broker resolves current credentials/registered endpoint on every call. Authenticate actual consumer delegation and validate tenant/workload/audience/source generation before provider access and page admission. Host redirects and next links cannot select arbitrary URL/private network destinations.

### Retained implementation requirements

- **Deliverables and entry points:** Proposed modules/connectors/devlake/cmd/connector-api and versioned OpenAPI: capabilities, validate, discover, describe. Extract provider functions with injected clients/helpers; no mutable tenant globals. Extend gateway discovery and an explicit delegated credential-broker path.
- **Inputs and configuration:** Operation/request IDs, connection_ref, optional binding generation, capability, opaque cursor and deadline. Gateway supplies an operation-bound handle; verified TLS/workload identity required. Broker resolves approved endpoint and current credentials before each provider request.
- **Outputs and behavior:** One bounded page of native IDs, namespace, typed facts, revision/digest/time and coverage/cursor; sanitized errors. Gateway commits cursor/results under its lease. Preserve old numeric-page operations through a versioned adapter.
- **Compatibility and data:** No persistent duplicate secrets or direct vault-wide access. ADP owns OAuth refresh and GitHub App keys. Broker checks real actor/consumer delegation; service identity alone grants nothing. Recheck generation/grants before admission/save; late revoked results are discarded.

The canonical architecture resolves placement, policy, publication and lifecycle details when the older implementation-contract summary is less specific. It does not relax any acceptance predicate. Common six-field identities, native provenance and current authorization remain mandatory.

## Fixtures, independent oracles and completion

Trace actual extracted functions for GitHub installation namespaces and Jira boards through gateway → Go → broker → provider; native authorized readback is the oracle. Rotate/revoke credentials and pause a pending response; generation fence rejects late results. Concurrent tenant/Project requests cannot share tokens/client state. Test five-page/30-second cap, throttle, process loss and durable cursor resume; report partial/unsupported explicitly.

Use the [shared verification controls](../verification.md#fixture-and-determinism-contract). Pin code, requirements, source revisions, clocks, routing/policy epochs and cleanup ownership. A plausible wrong result must fail the independent oracle, not merely match an implementation-generated fixture.
