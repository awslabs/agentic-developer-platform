Reasoning and confidence

Verdict: no malicious behavior observed (deliberate, self-identified anti-malware test site). Confidence: medium-high. Live isolated browsing of https://malware.wicar.org (host scope, desktop profile) returned HTTP 200 and the page immediately navigated to https://www.wicar.org/test-malware.html, titled "Test Malware! - WICAR.org - Test Your Anti-Malware Solution!". The rendered page and screenshot show a catalogue of clearly labelled, opt-in test payloads (EICAR test file, CVE-2014-6332 MS14-064, CVE-2012-4681 Java 7 applet, MS03-020, MS05-054, MS09-002, MS09-072, MS10-090, Firefox exposedProps CVE-2012-3993, VLC AMV CVE-2010-3275, Adobe Flash CVE-2015-5119, and a JavaScript crypto miner), each in HTTP and SSL variants under malware.wicar.org/data/, plus instructions that "Ideally, all tests should be blocked by your anti-malware defences" and a liability disclaimer. Nothing was auto-served on load: only the two document requests were recorded, with no drive-by script, redirect chain to third-party infrastructure, or automatic download. Common Crawl historical evidence (2021-2026, crawls CC-MAIN-2021-43 through CC-MAIN-2026-39) shows the same structure has been publicly archived for years; the 2025-01-23 root capture is only a 301 redirect, consistent with the live redirect to www.wicar.org. The site's stated purpose is security-control testing, but it does host real exploit and miner content behind user-initiated links; that content was not activated or executed in this assessment, so its current live payloads remain untested.

Recommended next steps

  • Treat malware.wicar.org as intentional test content: allow it only from isolated, instrumented test hosts and keep it blocked on production endpoints and user networks.
  • If validating controls, expect EICAR and the listed CVE test pages to be blocked; an unblocked blank page indicates the control did not detect the test, per the site's own guidance.
  • Do not fetch or execute /data/ resources (eicar.com, exploit HTML, js_crypto_miner.html) outside a disposable sandbox; the JavaScript miner is advertised as consuming significant CPU.
  • If an endpoint alert cites this domain, correlate with whether a sanctioned test was in progress before treating it as a real compromise.
